## Hinweise

- Schutzgebiete betreffen die untere Naturschutzbehörde. Hier ist das die Stadt Hamburg selbst.
- Im Kartengebiet liegt die Schutzzone III des Wasserschutzgebiets „Süderelbmarsch/Harburger Berge“. Dort sind Veranstaltungen meist möglich; was die Verordnung erlaubt, sagt die untere Wasserbehörde.
- Zuständige Forstdienststelle für den Wald im Kartengebiet: Revierförsterei Hausbruch (Bezirksamt Harburg). Fragen Sie dort früh nach, wenn Sie eine Veranstaltung im Wald planen.
- Zuständige Forstdienststelle für den Wald im Kartengebiet: Revierförsterei Eißendorf (Bezirksamt Harburg). Fragen Sie dort früh nach, wenn Sie eine Veranstaltung im Wald planen.
- Für eine Veranstaltung im Wald brauchen Sie die Zustimmung der Waldbesitzer. Wem der Wald gehört, kann meist die Forstdienststelle sagen. In mehreren Bundesländern ist eine organisierte Veranstaltung im Wald außerdem der Forstbehörde anzuzeigen oder von ihr zu genehmigen.
- Im Kartengebiet liegt Erholungswald (von hoher Bedeutung). Für Veranstaltungen dort fragen Sie die Forstbehörde.
- Im Kartengebiet liegt Bannwald oder Schutzwald (Reiherberg). Fragen Sie die Forstbehörde, bevor Sie dort eine Veranstaltung planen.
- Für Straßen, Plätze und Grünanlagen im Bezirk Harburg ist meist das Bezirksamt Harburg zuständig, dort das Fachamt Management des öffentlichen Raumes.
- Für die Denkmale im Kartengebiet ist das Denkmalschutzamt Hamburg zuständig.
- Eigentümer dieser Flächen sind aus offenen Daten nicht bestimmbar. Bei berechtigtem Interesse (z. B. Veranstalter) kann beim Grundbuchamt ein Grundbuchauszug beantragt werden; für öffentliche Flächen hilft das zuständige Ordnungs- oder Grünflächenamt.
