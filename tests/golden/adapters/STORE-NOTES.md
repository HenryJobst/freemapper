Test data for freemapper's own tests, not a program release. To install freemapper, take the
[latest release](https://github.com/HenryJobst/freemapper/releases/latest).

The archive holds recorded answers of the open data services of German states for small test
areas (about 150 m square each) and the OpenStreetMap objects of the same areas. The tests replay
them, so they need no network. `tests/golden/adapters/README.md` in the repository explains how.

Each state's folder in the archive has an `ATTRIBUTION.txt` with the source and the licence of
its data. The OpenStreetMap objects are © OpenStreetMap contributors, ODbL 1.0.
