# 0152. AGPL-3.0-or-later

Date: 2026-11-15
Status: Accepted, supersedes ADR 0006

## Context
ADR 0006 chose GPL-3.0-or-later. The GPL lets anyone run a modified copy as a network service without
publishing the changes. The author holds all copyright in freemapper and the three other suite repositories
(one author in every history), so the licence can change for new versions. The third-party crates are permissive
(MIT, Apache-2.0, BSD, ISC, Zlib, Unicode) or offer such a licence as an option; `option-ext` is MPL-2.0. All
combine with the AGPL. The OpenOrienteering Mapper symbol sets stay GPL-3, which GPLv3 section 13 allows to
combine with an AGPLv3 work.

## Decision
freemapper is licensed AGPL-3.0-or-later, as freemapper-core (core ADR 0035), freemapper-print and
freemapper-courseplan. The OpenOrienteering Mapper files keep GPL-3.0 and say so in
`assets/symbol-sets/README.md`.

## Consequences
- Whoever runs a modified freemapper as a network service must offer its source to the users (section 13). Local
  use, the CLI and the MCP server on the user's own computer do not change.
- Releases up to v0.22.0 stay GPL-3.0-or-later for those who received them.
- A fork under another name stays allowed, as it was under the GPL.
- Cost if wrong: a user who needs the GPL without the network clause has no licence for new versions; the
  author could grant one.

Source: the licence audit of 2026-11-15; freemapper-core ADR 0035.

## Addendum 2026-11-15
The area page (`freemapper select`) shows a footer link "Source code (AGPL-3.0-or-later)" to the repository, so that
a modified copy run as a service already offers its source to the users (section 13) without further work.
