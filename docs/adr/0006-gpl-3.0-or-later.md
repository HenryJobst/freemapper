# 0006. GPL-3.0-or-later

Date: 2026-11-06
Status: Accepted

## Context

freemapper embeds OOM's symbol sets (ISSprOM 2019 and the school set derived from it) and uses OOM's
`OSM-ISSprOM 2019.crt` as a source for its rules. Both are GPL. Karttapullautin, a candidate engine for later
forest maps, is GPL-3.0 too. The spec lists GPL-incompatible reuse of OOM symbol sets as an anti-goal.

## Decision

freemapper is licensed GPL-3.0-or-later.

## Consequences

- The OOM symbol sets can ship inside the binary.
- Anyone who distributes freemapper or code built on its library must do so under the GPL.
- Cost if wrong: relicensing later needs the consent of every contributor and a replacement for the embedded
  GPL symbol sets.

Source: spec §2 (anti-goals), §3 (Licence), §4.3; plan-mode notes ("Lizenz: GPL-3.0", Karttapullautin research).
