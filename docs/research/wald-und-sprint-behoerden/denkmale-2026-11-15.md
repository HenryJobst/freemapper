# Monument services per state (research, 2026-11-15)

Research for the permit notes: open services with listed monuments in the states other than Berlin, Hamburg and
Saarland. Done by a research agent with curl and the fixed freemapper User-Agent; read-only, small boxes.

Every request used `curl` with the User-Agent `freemapper/0.15 (+https://github.com/HenryJobst/freemapper)`. All were GET, with small boxes and at most 50 features. No repository file was changed. Scratch files are in `/tmp/claude-502/denkmal/`. I found licences in GDI-DE catalogue records, read with `https://gdk.gdi-de.org/geonetwork/srv/eng/csw?...request=GetRecordById&outputSchema=http://www.isotc211.org/2005/gmd&id=<uuid>`. The catalogue UUIDs are given below. Where a service's own capabilities state a licence, I quote that too. No service I tested holds private owners' names.

### Brandenburg: usable now (attribution is clear; the licence is named for Bodendenkmale only)
- **Baudenkmale:** WFS 1.1/2.0 (MapServer) at `https://gis-bldam-brandenburg.de/ows/baudenkmale`. Output is GML only; `application/json` is refused with 400.
  - Feature types: `ms:Baudenkmal-Punkt`, `ms:Baudenkmal-Polygon`, `ms:Baudenkmal-Linie`, `ms:Baudenkmal-Gartendenkmal`, `ms:Baudenkmal-Gewaesser`, `ms:Baudenkmal-sonstige-Flaeche`, `ms:Denkmal-mit-Flaechencharakter` (this one is for Denkmalbereiche).
  - Default CRS is EPSG:25832. A bbox in EPSG:4326 returned 0 features, so send it in 25832.
- **Bodendenkmale:** `https://gis-bldam-brandenburg.de/ows/bodendenkmale` with `ms:Bodendenkmal-Flaechen`, `ms:Bodendenkmal-Oberirdisch-Punkte`, `ms:Bodendenkmal-Grabungsschutzgebiete`.
- **INSPIRE variants:** `https://gis-bldam-brandenburg.de/inspire/wfs_ps_baudenkmale` and `.../inspire/wfs_ps_bodendenkmale`. Their capabilities are listed in the catalogue; I did not test them.
- **Attributes:**
  - Baudenkmale: `datensatzn` (the list number), `listentext` (the description), `kreis`, `gemeinde`, `ort`, `adresse`, `datierungen`. There is no link and no authority field.
  - Bodendenkmale: only `id`, `kreis`, `datum`.
- **Licence:**
  - Bodendenkmale: dl-de/by-2.0. Credit line: `Quelle: © Denkmaldaten/Brandenburgisches Landesamt für Denkmalpflege und Archäologisches Landesmuseum (BLDAM), dl-de/by-2-0` (records 2e07edfc…, fdac2ccb…).
  - Baudenkmale (records b8e231db…, 6879d84e…): the records name no licence. They only say `Bei Nutzung der Daten muss eine Namensnennung erfolgen: © Denkmaldaten/BLDAM <aktuelles Jahr> (Daten geändert = optional)`.
  - The capabilities say Fees `keine`, AccessConstraints `keine` for Baudenkmale. For Bodendenkmale, AccessConstraints repeats the Namensnennung text.
- **Test:** box `768000,5806500,769500,5807500` in EPSG:25832 (Petzow/Werder, next to Potsdam), all HTTP 200:
  - Baudenkmal-Polygon: 11
  - Gartendenkmal: 2
  - Denkmal-mit-Flaechencharakter: 1
  - Bodendenkmal-Flaechen: 17 (in a slightly larger box)
  - Sample: `datensatzn=09191315, listentext="Garage", gemeinde="Werder (Havel)", ort="Petzow", adresse="Am Schwielowsee 50", datierungen="Datierung 1928"`.
- **Personal data:** none.

The service record 44cea744… says `Es gelten keine Bedingungen`; the WMS capabilities say Fees none, AccessConstraints none.

### Schleswig-Holstein: licence is clear, but there is no web service
- **Bau- and Gründenkmale (LDSH):** no WFS found. The open data portal has a weekly GeoJSON of the whole state, about 52 MB, in EPSG:25832. Stable URL: `https://opendata.schleswig-holstein.de/collection/geodaten-denkmalliste-sh/aktuell.geojson`, which redirects with 302 to the current file.
- **Attributes:** `LayerName` (for example `Baudenkmal`), `Kreis`, `Gemeinde`, `Strasse`, `Hausnummer`, `Ansprache`, `Art`, `Funktion`, `ObjNummer`, `FotoURL`, `Details` (always the general Denkmalkarte page), `Stand`.
- **Licence:** CC BY 4.0. The CKAN `licenseAttributionByText` is `Landesamt für Denkmalpflege Schleswig-Holstein` (package `geodaten-denkmalliste-sh-2026-11-09`).
- **Restrictions in the GDI-SH metadata:**
  - LDSH record cca9aae9…: `…nur für den internen Dienstgebrauch vorgesehen…`. This covers the original data; the open data file is an extract.
  - Archäologie (ALSH, record 47b912e4…): `…Weitergabe, Veröffentlichung, Präsentation im Internet … ist nur mit schriftlicher Einwilligung des Archäologischen Landesamtes Schleswig-Holstein zulässig.` So Bodendenkmale cannot be used.
  - Lübeck keeps its own list, which is not in this file.
- **Test:** a bbox query is impossible (bulk file only). I read the first 6 KB with a Range request (206). Sample: `LayerName="Baudenkmal", Gemeinde="Maasholm", Ansprache="Kahnstellen am Schleiufer", Art="Verkehrsbauten", ObjNummer="6761", Stand="09.11.2026"`.
- **Verdict:** possible only as a cached weekly bulk download (52 MB). That is a design question for freemapper.

## Ranking

**Ready to implement now (working service and a clear open licence):**
1. **Hessen:** GeoJSON, DenkXweb links, dl-de/by-2.0.
2. **Bremen:** list links, all three kinds, CC BY.
3. **Rheinland-Pfalz:** GeoJSON, Denkmalzonen, authority text, dl-de/by-2.0.
4. **Baden-Württemberg:** GeoJSON, dl-de/by-2.0, but only an `info` text and no kind or link.
5. **Sachsen:** GML, rich attributes, CC BY 3.0 DE. There is no fixed credit text; "Landesamt für Denkmalpflege Sachsen" is the holder.
6. **Brandenburg:** GML, bbox in EPSG:25832. Attribution is required; only the Bodendenkmal records name dl-de/by-2.0.
7. **Nordrhein-Westfalen:** GML, dl-de/zero-2.0. The data is still incomplete (Münster is empty), so a missing result must not be read as "no monuments".

**Need a question to the authority, or a design decision:**
- **Niedersachsen:** the API says CC BY-SA 4.0, the metadata says CC BY 4.0, the WMS says restricted. Ask the NLD (Niedersächsisches Landesamt für Denkmalpflege).
- **Bayern:** CC BY-ND 4.0. Ask the BLfD (Bayerisches Landesamt für Denkmalpflege) whether clipping and showing the data in permit notes counts as "Bearbeitung" (an adaptation, which the licence forbids).
- **Schleswig-Holstein:** CC BY 4.0, but only a 52 MB weekly bulk file. Decide whether freemapper may cache it. Archaeology needs written consent; Lübeck is separate.
- **Mecklenburg-Vorpommern:** district patchwork, about half the state covered, licences mixed or unclear (Rostock district: CC0 versus dl-de/by). Ask the LAKD (Landesamt für Kultur und Denkmalpflege) whether a statewide service is planned.
- **Sachsen-Anhalt:** the service is empty or broken for Baudenkmale and the licence contradicts itself (CC BY versus CC BY-NC-ND 3.0 DE). Ask the LDA (Landesamt für Denkmalpflege und Archäologie).
