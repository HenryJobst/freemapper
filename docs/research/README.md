# Recherche

Hier liegen die Recherchen, auf denen Entscheidungen und Pläne von freemapper beruhen. Sie sind Arbeitsstände mit Quellen und Stichtag, keine Anleitungen. Dienst-Adressen und Datenstände können sich ändern; prüfen Sie sie vor der Verwendung. Die Berichte nennen Pfade und Namen aus der Arbeitsumgebung der Sitzungen, die dort nicht mehr existieren.
