# freemapper-print answers on the gym symbol set (2026-11-08)

(a) Colours: purple 35/85/0/0 (IOF Rev. 4), brown 25/75/100/0; deviate only if the final ISInOM demands it. Darker purple for barrier tape (45/100/0/0, 1775) fine as its own symbol.
(b) Court lines: default neutral grey (Black 50 %, 0.12 mm); DIN colours optional in the reserved range 1970–1979, marked as not standard.
(c) Blue mats OK for print, but use a tint (e.g. Blue 50 %) with a darker outline, not Blue 100 % fill and edge.
(d) Map parts `hall`, `courts`, `equipment`, one .omap per equipment setup: agreed as the contract; print prints all parts and plans (M2) an option to hide parts, so names stay stable, change only with notice.
Request: mark size classes machine-readably. P symbols keep paper size across 1:100–1:500 (factor 1); G symbols (equipment footprints, dash/gap of dashed court lines) scale with the ground (geometry factor); line widths inside G symbols stay P. Proposal: a fixed entry in the symbol description (`freemapper:size=ground`) or a code list for the "Halle" print profile. Minimum footprint 0.6 mm also applied by print when rescaling.
