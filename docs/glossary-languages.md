# Begriffe der weiteren Sprachen / Terms of the other languages

Die Kataloge dieser Sprachen sind maschinell entworfen und nicht von Muttersprachlern gelesen (ADR 0169). Die Tabellen halten die gewählten Begriffe fest, damit eine Durchsicht an einer Stelle ansetzt. / The catalogs of these languages are machine drafts, not yet read by native speakers (ADR 0169). The tables record the terms chosen.
