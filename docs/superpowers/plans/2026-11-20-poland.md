# Poland Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A project anywhere in Poland runs `init`, `run` and `export` (schoolyard, sprint, forest), in Polish for Polish users.

**Architecture:** One national adapter `polska` in a new crate `crates/adapters/pl`, next to `crates/adapters/de`. The project grid stays UTM (zone 34 is new, chosen per map area); EPSG:2180 is a source grid for GUGiK rasters and vectors only. Five stages, each releasable: foundation + OSM, terrain + orthophoto, buildings + land use, Polish language, permit notes.

**Tech Stack:** Rust workspace; `freemapper-core` (separate repo, pinned by tag in `Cargo.toml`) for `Crs` and text; GUGiK WFS/ASC/GeoTIFF/GPKG; Geofabrik OSM extracts; Fluent `.ftl` catalogs.

**Spec:** `docs/superpowers/specs/2026-11-20-poland-design.md`. Research: `docs/regions/crossborder-reference.md` §2 (probed 2026-11-07, border strip only: **re-probe live at the start of stages 2, 3 and 5** and correct this plan where services differ).

## Global Constraints

- One adapter id `polska`; no voivodeship adapters; OSM extracts per voivodeship (`europe/poland/<name>`).
- Project grid is UTM: Utm32, Utm33 and new `Utm34` (EPSG:25834). EPSG:2180 (lon0 19°, k 0.9993, FE 500 000, FN -5 300 000, GRS80) is a source grid only.
- WFS 2.0 BBOX in EPSG:2180 takes **N,E**; returned data is **E,N**.
- Heights PL-EVRF2007-NH, no correction to DHHN2016. Never use KRON86 or the 0.05 m orthophoto (use 0.25 m).
- Map area must lie wholly in Poland in stage 1; one that reaches another country fails with a message.
- Poland is announced as **preview** (README row, manual, release notes) until stage 4 is done. Texts a Polish user reaches never say "Bundesland" and name no German law.
- No e-mail address or personal data in any request (User-Agent is fixed). Credit: "Źródło: Główny Urząd Geodezji i Kartografii (geoportal.gov.pl)" (our wording), plus "© OpenStreetMap contributors (ODbL)" and the freemapper credit line.
- Source code and technical docs in English, terms per `docs/glossary.md`; user docs German and English (Polish from stage 4). Every merge: ADR (next free number, check `docs/adr/`; 0159 at the time of writing), `CHANGELOG.md` and `CHANGELOG.en.md` entry, README region row, manual update. PR label `all-systems`. Watch `ci.yml` on all three systems after merge. Checks as `AGENTS.md` lists them: `cargo fmt --all --check`, `cargo clippy --workspace --all-targets -- -D warnings`, `cargo test --workspace --locked`, `cargo deny check`.

## Review Focus

Failure modes the spec implies that no task would otherwise test; each has its test in the owning task.

1. A map area that straddles the UTM 33/34 border (Wrocław, Kraków, Warsaw region): one zone for the whole project, objects not torn at the seam. → Task 1.2.
2. An area partly outside Poland (Słubice/Frankfurt, Cieszyn/Český Těšín): refused with a message, never a half map. → Task 1.7.
3. Polish diacritics (`Łódź`, `Świnoujście`, `Września`) in titles, project folder names, `.omap` and PDF text. → Task 1.8.
4. GUGiK sheets are not aligned with the grid and carry nodata corners: no holes in contours or hillshade where two sheets meet. → Task 2.5.
5. EGiB WFS refuses, times out or caps the count: fall back to BDOT10k buildings with a warning, no failed run. → Task 3.2.
