# M7: Sprint Map for Strausberg Vorstadt – Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `freemapper run` on a sprint project (1:4000, ISSprOM 2019) writes paved areas from the ALKIS
land use and unpaved paths from OSM as map objects, and the uncertain rest (ALKIS ways, OSM paths
without a surface) as candidates.

**Architecture:** The OSM rule file gains numeric conditions (`width<1.5`) and a per-rule `layer`
(`candidates`, default, or `map`); the OSM builder returns the objects of one layer, so export calls
it once for the map and once for the candidates. A new builder `build/paved.rs` turns stored ALKIS
land use (`data/alkis-land-use.geojson`, already fetched since M5b) into 501.5 objects; its clipping
and sliver filter are shared with the out-of-bounds builder. Everything is sprint only.

**Tech Stack:** no new crates.

**Spec:** `docs/superpowers/specs/2026-11-07-freemapper-design.md` §4.5 (paths and areas, sprint only),
§6 M7.

## Global Constraints

- Live ALKIS values around Strausberg Vorstadt (2026-11-07, bbox 421000,5820800–422200,5821800):
  `Straßenverkehr` (with or without `bez = Begleitfläche Straßenverkehr`), `Weg`, `Platz`
  (`bez = Parkplatz` or none), `Bahnverkehr`. Checked over the orthophoto: `Straßenverkehr` without
  `bez` is carriageway with sidewalks and parking lanes; `Begleitfläche` is green verges with trees and
  some sidewalk; `Weg` is sidewalks and paved lanes here, but forest tracks elsewhere; `Platz` is paved.
- Map objects 501.5 (paved area, light traffic, no border): `Straßenverkehr` without `Begleitfläche`,
  `Platz`. Candidate 501.5: `Weg`. Not drawn: `Begleitfläche Straßenverkehr` (the orthophoto shows it).
  `Bahnverkehr` stays a 520 candidate (M5b). Heavy-traffic symbols are not used (ALKIS has no traffic volume).
- OSM ways (spec §4.5), first matching rule decides, all with `footway!=sidewalk|crossing`:
  unpaved = `surface=unpaved|dirt|earth|ground|grass|gravel|fine_gravel|compacted|sand|woodchips`;
  506 map: `highway=track|path|footway|bridleway` + unpaved + `width<1.5`; 506 map: `highway=path` +
  unpaved + `trail_visibility=intermediate|bad|horrible|no`; 505.2 map (2 m footprint):
  `highway=track` + unpaved; 505.1 map (1.4 m): `highway=path|footway|bridleway` + unpaved;
  505.1 candidate: `highway=track|path|footway|bridleway` + `surface!=*`. Paved ways: no rule.
- Numeric condition `key<number`: holds when the value parses as a number (an optional ` m` suffix
  allowed, decimal comma accepted); otherwise it does not hold.
- Clip like out-of-bounds: map area bounding box plus buffer; drop pieces below (1 mm)² or narrower
  than 1 mm on paper. Tags: `freemapper:source = alkis-nutzung`, `freemapper:source_id = <oid>`,
  `freemapper:nutzart = <nutzart[ / bez]>`, `freemapper:currency = <aktualit>`.
- Glossary first: `Verkehrsfläche` / traffic area, `Begleitfläche` / verge.

## Review Focus

1. **A way tagged both `surface=asphalt` and `width=1`** – paved, so no path object (rules order).
2. **`width=1,2 m`, `width=narrow`** – numeric parse with comma and unit; non-numbers never match.
3. **Schoolyard projects** – unchanged: no 501.5, no 505/506 objects.
4. **A traffic parcel crossing the clip edge** – clipped, no slivers.
5. **Projects stored before M7** – export works; stored OSM features without highways just give no paths.

### Task 1: Rules for unpaved paths
`assets/rules/osm-candidates.toml` (header explains `layer` and `<`), `build/candidates.rs`: `Condition`
gains a numeric below variant; `RuleEntry`/`Rule` gain `layer: Layer` (`Layer::{Candidates, Map}`, serde
lowercase, default candidates); `Match.layer`. Glossary entries. Tests: `width_below_is_numeric`
(`1.2`, `1,2 m` hold for `<1.5`; `2`, `narrow` do not), `unpaved_track_is_a_map_object`,
`narrow_or_faint_path_is_506`, `paved_and_sidewalk_ways_are_dropped`,
`path_without_surface_is_a_candidate`, `schoolyard_has_no_path_rules`.

### Task 2: OSM map objects in the export
`candidate_objects` → `osm_objects(features, rules, layer, kind, …)`; export puts `Layer::Map` objects
into the map's default part and `Layer::Candidates` into `candidates.omap`. Tests:
`export_puts_unpaved_paths_into_the_sprint_map`, `export_puts_paths_without_surface_into_candidates`.

### Task 3: Paved areas from ALKIS land use
`build/paved.rs`: `paved_area_objects(land_use, clip, georef, symbol_set) -> Result<PavedObjects { map,
candidates }, GeorefError>`; shared `clipped_land_objects` with out_of_bounds. Export (sprint only) adds
`map` to the default part, `candidates` to the candidates part. Tests: `traffic_areas_are_paved`,
`verges_are_left_out`, `ways_are_candidates`, `paved_area_is_clipped`, `paved_tags_carry_provenance`,
`export_adds_paved_areas_to_sprint_map`, `schoolyard_export_has_no_paved_areas`.
