# Berlin Adapter – Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Maps in Berlin and across the Berlin/Brandenburg border get buildings, land use and an nDSM
template like Brandenburg maps.

**Architecture:** A region layer decides per area which ALKIS sources apply: Brandenburg (LGB OGC
API), Berlin (Geoportal Berlin WFS) or both. Berlin features are normalised into the LGB property
schema and merged, so the stored files, records and build rules stay as they are.

The LGB rasters already cover Berlin (DOP20, DGM1). The nDOM LAZ is missing inside Berlin, so
there the nDSM comes from the LGB bDOM (0.2 m GeoTIFF) minus the DGM1.

Attribution names the Geoportal Berlin when Berlin data is used.

**Tech Stack:** no new crates.

**Spec:** `docs/superpowers/specs/2026-11-07-freemapper-design.md` §4.1 and "Later: Berlin adapter".
Verified sources (2026-11-07): `docs/regions/berlin-reference.md`, a copy of the research reference.

## Global Constraints

- **Region:** `assets/regions/berlin.geojson` is the Berlin boundary from ALKIS `alkis:land` (EPSG:25833,
  simplified 25 m; dl-de/zero-2-0).
  - Berlin applies if the bbox widened by 100 m intersects the boundary.
  - Brandenburg applies if the widened bbox is not inside the boundary.
  - Both apply near the border.
- **Berlin WFS:**
  - Buildings: `https://gdi.berlin.de/services/wfs/alkis_gebaeude`, type `alkis_gebaeude:gebaeude`.
  - Land use: `https://gdi.berlin.de/services/wfs/alkis`, type `alkis:tatsaechlichenutzungflaechen`.
  - Query parameters: `service=WFS&version=2.0.0&request=GetFeature&typeNames=…&outputFormat=application/json&count=5000&bbox=E,N,E,N,urn:ogc:def:crs:EPSG::25833`.
  - Paging follows `links[rel=next]`.
  - Up to 3 attempts per page.
  - A body that is not a JSON FeatureCollection is an error, even with HTTP 200.
- **Normalisation of buildings** into LGB properties:
  - `oid` = `uuid`
  - `gebnutzbez` = `Gebäude` / `Bauteil` from `bezeich` (`AX_Gebaeude` / `AX_Bauteil`)
  - `funktion` = `bezgfk`
  - `rellage` = `bezofl`
  - no `aktualit`
- **Normalisation of land use:**
  - `oid` = `uuid`
  - `nutzart` = German class name from `bezeich`, e.g. `AX_Wohnbauflaeche` → `Wohnbaufläche`,
    `AX_Strassenverkehr` → `Straßenverkehr`, `AX_Weg` → `Weg`, `AX_Platz` → `Platz`,
    `AX_Bahnverkehr` → `Bahnverkehr`, `AX_IndustrieUndGewerbeflaeche` → `Industrie- und Gewerbefläche`,
    `AX_FlaecheGemischterNutzung` → `Fläche gemischter Nutzung`; full table in Task 2
  - `bez` = `bezfkt` if not empty
  - **Berlin `Platz` without `bezfkt` gets `bez = "ohne Unterart (Berlin)"`**, so it stays a candidate: Berlin
    never refines squares, and festival grounds would otherwise become paved map objects.
- **Merge:** features of both sources in one FeatureCollection; ids never collide (`DEBE…` / `DEBBAL…`).
- **nDSM:** where the LGB nDOM tile is 404, fetch `bdom/tif/bdom_33EEE-NNNN.zip` (currency
  `bb_bdom_aktualitaet.csv`).
  - Derive: nDSM = bDOM − DTM (bilinear), clamped at 0, on the 0.2 m grid.
  - LAZ points take precedence where both exist.
- **Attribution:**
  - The LGB line gains `; © Geoportal Berlin, dl-de/zero-2-0` when the area touches Berlin.
  - Plus a line `Geoportal Berlin / ALKIS Berlin, dl-de/zero-2-0` when Berlin ALKIS data was used.
  - DE sheet text: `© GeoBasis-DE/LGB <Jahr>, dl-de/by-2-0; © Geoportal Berlin, dl-de/zero-2-0, Daten geändert`.

## Review Focus

1. **A Berlin area today gets 0 buildings silently.** After this change it gets the Berlin buildings; an area
   where both sources return nothing reports a warning.
2. **Border area** (Teltow/Lichterfelde): buildings of both sources, no duplicates.
3. **gdi.berlin.de resets connections or answers 200 with XML:** retried, then a clear error. The stored
   buildings stay (existing rule).
4. **Projects fetched before:** export works unchanged; a Brandenburg-only area makes no Berlin request.
5. **nDSM in Berlin:** the template exists, heights are plausible (trees 10–25 m, houses), and there is no seam
   where LAZ and bDOM tiles meet.
